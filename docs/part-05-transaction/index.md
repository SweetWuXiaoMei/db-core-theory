# 第五部分：事务与并发控制

本部分学习数据库最核心的保障机制：ACID 事务、日志恢复和多用户并发控制。

## 章节列表

| 章节 | 主题 | 核心收获 |
|------|------|----------|
| [第 12 章](chapter-12-transaction.md) | 事务管理 | ACID 特性与实现原理 |
| [第 13 章](chapter-13-log.md) | 日志系统 | Redo/Undo 日志与崩溃恢复 |
| [第 14 章](chapter-14-concurrency.md) | 并发控制 | 锁机制与 MVCC 多版本控制 |

## 学习目标

完成本部分后，你将能够：

- 理解 ACID 四大特性的含义和实现方式
- 掌握 WAL（Write-Ahead Logging）机制
- 实现 Redo 日志（恢复已提交数据）和 Undo 日志（回滚未提交数据）
- 理解锁机制和 MVCC 多版本并发控制
