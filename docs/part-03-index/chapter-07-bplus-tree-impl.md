## 详尽理论

### B+树节点的设计

#### 内部节点（Internal Node）
```
┌──────────────────────────────────────┐
│ 键值[0] │ 键值[1] │ ... │ 键值[n-1]  │
├──────────────────────────────────────┤
│ 子节点[0]│子节点[1]│ ... │子节点[n]    │
└──────────────────────────────────────┘
子节点数量 = 键值数量 + 1
```

#### 叶子节点（Leaf Node）
```
┌──────────────────────────────────────┐
│ 键值1→数据1 │ 键值2→数据2 │ ...       │
├──────────────────────────────────────┤
│ 指向下一个叶子节点的指针 →             │
└──────────────────────────────────────┘
```

## Java实战Demo

### 项目结构

```
chapter-07-bplus-tree-impl/demo/
├── pom.xml
└── src/main/java/com/ourdatabase/index/
    ├── BPlus树.java        (B+树的完整实现)
    └── BPlus树演示.java    (主程序，演示所有操作)
```

### B+树核心API

| 方法 | 说明 |
|------|------|
| insert(key, value) | 插入键值对 |
| search(key) | 精确查找 |
| rangeSearch(start, end) | 范围查询 |
| delete(key) | 删除 |
| print() | 打印树结构 |

### 运行步骤

```bash
cd chapter-07-bplus-tree-impl/demo
mvn compile
mvn exec:java -Dexec.mainClass="com.ourdatabase.index.BPlus树演示"
```
